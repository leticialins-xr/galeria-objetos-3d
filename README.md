# Acervo 3D · InovaGov Acre

Galeria web para visualização dos objetos históricos digitalizados em 3D no âmbito do InovaGov Acre.

## Objetos disponíveis

- Batelão
- Baú de seringalista
- Figurino do Exército
- Marcador de Madeira
- Péla de borracha
- Rádio antigo
- Relógio de ponto

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O projeto usa Vite e Three.js. Os modelos otimizados ficam em `public/models` e são carregados sob demanda.
